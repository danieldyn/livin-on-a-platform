# Item Codifications

- `-` <=> ignored block (for pattern matching)
- `0` <=> background block
- `1` <=> dirt block
- `2` <=> grass block
- `3` <=> water block
- `4` <=> coin
- `5` <=> spike block
- `6-9` <=> chest tier 1-4 (value increasing)
- `a` <=> tree
- `b` <=> end of level flag
- `c` <=> enemy (slime)
- `d` <=> heart
- `e` <=> mushroom
- `f` <=> flower
- `g` <=> underground tile 1
- `h` <=> underground tile 2
- `i` <=> stone block
- `j` <=> cobblestone tile 1
- `k` <=> cobblestone tile 2
- 's` <=> secret acorn
